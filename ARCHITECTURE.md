# Архитектура

Расширение Manifest V3 из пяти частей. Каждая живёт в своём контексте браузера и общается с остальными сообщениями.

```
 страница с видео                                  расширение
┌──────────────────────────────────────┐        ┌────────────────────────────────────────────┐
│ youtube-main.js (MAIN world)         │        │ background.js (service worker)             │
│  перехват /api/timedtext, API плеера │        │  настройки, кэш IndexedDB                  │
│            │ postMessage             │        │  TranslationEngine: очередь, приоритеты,   │
│            ▼                         │  port  │   отмена, дедупликация, запасные варианты  │
│ content.js (isolated world)          │◄──────►│  AnalysisService: словарь + правила        │
│  адаптер (YouTube / HTML5)           │        │  провайдеры:                               │
│  Controller: время, единицы перевода │        │   opus-browser ──► offscreen.html          │
│  Overlay (shadow DOM): строки, карточка│      │                     └► mt.worker.js (ONNX) │
└──────────────────────────────────────┘        │   local-service ──► http://127.0.0.1:8765  │
                                                │   ollama ─────────► http://127.0.0.1:11434 │
 popup.html: настройки и диагностика ◄─────────►└────────────────────────────────────────────┘
```

## Поток одной строки

1. **Адаптер** получает полный список титров видео с временами (`Cue[]`) и отдаёт его контроллеру. Для YouTube это JSON-ответ `/api/timedtext`, который плеер запрашивает сам; для HTML5 это `TextTrack.cues` немецкой дорожки.
2. **Контроллер** склеивает титры в единицы перевода (`src/core/context.ts`): если строка не кончается точкой, вопросом или восклицанием, а следующая начинается с маленькой буквы и идёт не позже чем через 1,6 с, они переводятся вместе. Предел: 4 титра или 260 символов. Без склейки «den ich seit Jahren nicht gesehen hatte» переводится как отдельная фраза и теряет смысл: на тестовом наборе chrF склеенных фрагментов 73,6 против 55,9 для переведённых по отдельности.
3. По событиям видео (`timeupdate` приходит примерно 4 раза в секунду, плюс `seeking`, `ratechange` и др.) и по таймеру точно на границе следующего титра (`timeline.nextBoundary`) контроллер смотрит `video.currentTime`, показывает текущую строку и отправляет в фон запрос на перевод: текущая единица с приоритетом 0, следующие 12 (настройка «Перевод наперёд») с приоритетом 1–2.
4. **TranslationEngine** проверяет кэш, ставит задачи в очередь провайдера, собирает их в пакеты, отменяет то, что стало не нужно после перемотки, и при ошибке переходит к следующему провайдеру цепочки.
5. Перевод возвращается через тот же порт. Контроллер кладёт его в память вкладки и показывает, если строка ещё на экране.
6. Параллельно **AnalysisService** разбирает немецкое предложение (с учётом перевода, если он уже есть). Карточка слова строится из этого разбора без новых запросов.

## Адаптеры (`src/content/adapters`)

Интерфейс `SubtitleAdapter`: `start(sink)`, `stop()`, `listTracks()`, `selectTrack(id)`. Через `AdapterSink` адаптер сообщает:

- `onCues(cues, track)`: полный список титров;
- `onLiveCue(text)`: строка без заранее известного времени (запасной режим);
- `onStatus(status)`: `searching`, `ready`, `no-video`, `no-subtitles`, `no-german`, `waiting-captions`, `blocked` с текстом для пользователя;
- `onSuspend(reason)`: временно скрыть строки (реклама на YouTube);
- `controlsInset()`: на сколько поднять блок над панелью управления плеера.

**YouTube** (`youtube.ts`, `youtube-parse.ts`, `src/inject/youtube-main.ts`). Скрипт в MAIN world оборачивает `fetch` и `XMLHttpRequest.open`, ловит ответы `/api/timedtext` и пересылает их через `postMessage` на канале `mitlesen`. Он же отвечает на запросы `list-tracks` / `set-track` через API элемента `#movie_player`. Сам адрес субтитров расширение не подделывает и запросов от себя не шлёт: YouTube требует к нему токен, который выдаёт только плеер. Порядок выбора дорожки: ручная немецкая, затем автоматическая немецкая. Автоматические субтитры YouTube идут «ползущими» фрагментами; парсер JSON3 убирает повторы и собирает из них строки. Если ответ так и не пришёл, через сторожевой таймер адаптер переходит на чтение `.ytp-caption-segment` из DOM. Пустой ответ YouTube отдельно объясняется пользователю (статус `blocked`).

**HTML5** (`html5.ts`). Выбирает самое большое видео на странице и немецкую дорожку (`srclang` или `label`), переводит её в режим `hidden`, чтобы браузер загрузил титры, но не рисовал свои. Ждёт события `load` у элемента `<track>`, повторяет попытки через 250 мс, 1 с, 2,5 с, 5 с и через 8 с без титров сообщает, что текст дорожки недоступен (обычно файл с другого домена без CORS).

Новый сайт добавляется новым классом с тем же интерфейсом и строкой выбора в `src/content/index.ts`.

## Оверлей (`src/content/overlay`)

Shadow DOM поверх видео, поэтому стили страницы на него не влияют. Немецкая строка разбита на `<span class="w">` с номером токена. Наведение открывает карточку через 90 мс, уход закрывает через 180 мс; если карточку только что закрыли, следующая открывается сразу, без задержки (350 мс). Клик закрепляет карточку, `Esc` закрывает. События мыши внутри блока не доходят до плеера: клик по слову не переключает паузу и двойной клик не включает полноэкранный режим. Пауза на время открытой карточки есть, но это отдельная настройка («Пауза, пока открыта подсказка»). Блок поднимается над панелью управления, когда она видна. В полноэкранном режиме оверлей переносится в элемент, который стал полноэкранным; если это голый `<video>`, в который ничего вставить нельзя, расширение временно включает собственные титры браузера (`NativeCues`), чтобы строки не пропали.

Карточка (`wordView.ts`) строится из `WordAnalysis` и показывает только то, что разбор знает. Поле с пометкой `likely` или `uncertain` выводится с отметкой «Определено неточно».

## Перевод (`src/background/translation`)

Провайдер реализует `TranslationProvider`: `id`, `speed` (`fast`/`slow`), `batchSize`, `abortable`, `usesContext`, `usable(now)`, `check()`, `translate(batch, signal)`. Общий класс `ProviderHealth` после ошибок делает паузы 4 с, 16 с, 60 с, чтобы не долбить упавший сервис.

| Провайдер | Где работает | Контекст | Пакет | Отмена |
|---|---|---|---|---|
| `opus-browser` | Web Worker в offscreen-документе | нет | 2 | нет (WASM не прерывается) |
| `local-service` | Python, `127.0.0.1:8765` | нет | 4 | да |
| `ollama` | Ollama, `127.0.0.1:11434` | да: 2 строки до, 1 после | 1 | да |

Цепочки: режим «В браузере» → `[opus-browser]`; «Сервис Mitlesen» → `[local-service, opus-browser]`; «Ollama» → `[ollama, local-service, opus-browser]`.

`TranslationEngine` (`engine.ts`):

- **Дорожки.** У каждого провайдера своя очередь и свой счётчик занятых слотов.
- **Приоритеты.** 0 — строка на экране, 1 — ближайшие, 2 — дальние. Срочная задача обгоняет фоновые; у провайдеров с отменой фоновая работа прерывается ради срочной.
- **Дедупликация.** Ключ задачи = провайдер + текст (+ контекст для Ollama). Две вкладки с одним видео делят одну задачу.
- **Отмена.** После перемотки контроллер присылает `cancel` со списком нужных ключей; остальные ожидающие задачи этой вкладки снимаются.
- **Запасной вариант.** Ошибка или неправдоподобный ответ (пусто, эхо немецкого, нет кириллицы, слишком длинно) → задача уходит следующему провайдеру цепочки.
- **Черновик.** Если основной провайдер медленный (Ollama), для строки на экране быстрый провайдер сразу делает черновик с пометкой `provisional`, потом его заменяет основной перевод.
- **Кэш.** Ключ `схема|провайдер|версия модели и промта|хеш текста и контекста`. Перевод одной модели не подставляется вместо перевода другой.
- **Метрики.** Окно последних 400 задержек на провайдера: среднее, медиана, p95. Видны в окне расширения.

Модель в браузере (`src/offscreen`). Service worker не может держать Web Worker, поэтому создаётся offscreen-документ (`reason: WORKERS`), а в нём module worker с transformers.js 4.3.2 и onnxruntime-web (WASM). Расширение изолировано (`COEP: require-corp`, `COOP: same-origin`), поэтому доступен `SharedArrayBuffer`, и ONNX Runtime запускает 4 потока. Модель читается из файлов расширения (`env.allowRemoteModels = false`), в сеть ничего не уходит. К тексту добавляется метка целевого языка `>>rus<<`, без неё модель de-zle может ответить по-украински или по-белорусски.

## Грамматика (`src/nlp`)

`analyzeSentence(sentence, dictionary, { translation?, parse? })` возвращает по одному `WordAnalysis` на токен. Шаги:

1. **Чтения.** Для каждого слова ищутся статьи словаря: точная форма, форма с другим регистром, отрезанное окончание прилагательного, элизия (`geht's`), слитные предлоги (`im`, `zum`), составное слово (последняя часть).
2. **Выбор чтения** по очкам: частотность, заглавная буква (в середине предложения — существительное), согласование с артиклем, «в клаузе только один спрягаемый глагол», есть ли у статьи русский перевод. Если есть разбор spaCy, его часть речи даёт +4.
3. **Клаузы** делятся по запятым и подчинительным союзам.
4. **Глаголы.** Спрягаемая форма, лицо и число по подлежащему. Последнее слово клаузы, если это возможная приставка (`auf`, `an`, `teil`…), склеивается с глаголом и проверяется по словарю: `stehe … auf` → `aufstehen`. Предлог (`Ich warte auf den Bus`) так не склеивается: за ним есть именная группа. Сложные времена (Perfekt, Plusquamperfekt, Futur I), пассив, модальные глаголы определяются по вспомогательному глаголу и форме второго глагола.
5. **Именные группы.** Артикль + прилагательные + существительное. Падеж определяется по артиклю и окончаниям, предлогу (`mit` → Dativ, `ohne` → Akkusativ, двойные предлоги по глаголу движения), позиции подлежащего.
6. **Значение в контексте** (`senses.ts`): если одно из русских соответствий слова встречается в переводе предложения, оно и есть значение (`likely`). Иначе берётся первое значение с пометкой `uncertain`. Омонимы с той же частью речи и родом («die Bank»: банк / скамья) делят общий список значений.

У каждого вычисленного факта есть `certainty`: `certain` (однозначно по форме), `likely` (выбор из вариантов по правилам), `uncertain` (догадка). Поля, взятые прямо из словаря (Partizip II, Präteritum, мн. число), считаются достоверными настолько, насколько достоверен словарь.

Если запущен локальный сервис, AnalysisService отправляет предложение в `/analyze` (spaCy `de_core_news_md`) и передаёт разбор анализатору как подсказку. Таймаут 2,5 с; без сервиса работает только словарь и правила.

## Словарь (`data/dict`, `src/nlp/dictionary.ts`)

Собран из трёх выгрузок Викисловаря (английский, русский, немецкий) и частотного списка по субтитрам фильмов. Подробно о сборке и лицензиях: [LICENSES_AND_ATTRIBUTION.md](LICENSES_AND_ATTRIBUTION.md).

- `meta.json`: версия, число статей, источники.
- `f/<0..511>.json`: форма слова → список `(номер статьи, грамматические коды)`. Шард выбирается по FNV-1a от формы в нижнем регистре.
- `e/<n>.json`: статьи по 500 штук, самые частые в первых файлах.

Статья: лемма, часть речи, род, мн. число, родительный падеж, формы глагола (настоящее время по лицам, Präteritum, Partizip II, вспомогательный глагол, отделяемая приставка, возвратность), степени сравнения, русские значения, немецкие определения, синонимы, пример. Расширение загружает только нужные шарды и держит их в памяти.

## Кэш (`src/background/cache/store.ts`)

`CacheStore<T>`: LRU в памяти перед IndexedDB (`mitlesen-cache`, версия схемы 1, хранилища `translations`, `analyses`, `meta`). У записи есть время последнего чтения. При чтении запись проверяется валидатором; испорченная удаляется. Лимиты: переводы 30 000 записей / 180 дней, разборы 1 500 / 30 дней. Лишние и просроченные записи удаляются после каждых 200 записей и по кнопке «Очистить кэш». Если IndexedDB не открылась или диск переполнен, кэш продолжает работать только в памяти, ошибки не выходят наружу.

## Сообщения и проверка (`src/shared/messages.ts`)

Все сообщения типизированы и проверяются функциями-охранниками до обработки. Фон принимает:

- порт `mitlesen` только от своих content-скриптов (`sender.id`);
- `chrome.runtime.sendMessage` только со страниц самого расширения (`sender.url` начинается с `chrome-extension://<id>/`);
- от страницы (MAIN world) только сообщения канала `mitlesen` с `event.source === window`, а адреса субтитров разбираются как URL YouTube.

Регистрация сайта принимает только шаблоны вида `https://host` или `*://*`.

## Service worker и его перезапуск

Браузер останавливает service worker через ~30 с простоя. Состояние, которое должно пережить это, лежит в `chrome.storage` (настройки) и IndexedDB (кэш). Content-скрипт переподключает порт и заново отправляет незавершённые запросы (`client.ts`, `onReconnect`). Offscreen-документ с загруженной моделью живёт отдельно и остановку service worker переживает. E2E-тест закрывает service worker посреди перевода и проверяет, что строки доходят.
