# Приватность

Коротко: текст субтитров не покидает ваш компьютер. У расширения нет своего сервера, аналитики, телеметрии и учётных записей.

## Что расширение читает

- **Субтитры видео.** На YouTube это ответ `/api/timedtext`, который плеер и так загружает; расширение читает копию этого ответа на странице и само к YouTube не обращается. На других сайтах это `TextTrack.cues` дорожки `<track>`.
- **Положение видео**: текущее время, пауза, скорость, полноэкранный режим. Нужно, чтобы показать нужную строку.
- **Адрес страницы** не сохраняется и никуда не отправляется. Окно расширения показывает только домен текущей вкладки, чтобы включить расширение для этого сайта.

## Куда уходит текст

| Режим | Куда | Что |
|---|---|---|
| В браузере | никуда: модель работает внутри расширения | — |
| Сервис Mitlesen | `http://127.0.0.1:8765` (или адрес, который вы указали) | строки субтитров для перевода, предложения для разбора spaCy |
| Ollama | `http://127.0.0.1:11434` (или ваш адрес) | строка и до трёх соседних строк контекста; слово и предложение для карточки |

Модель в браузере загружается только из файлов расширения: в коде worker стоит `env.allowRemoteModels = false`, загрузка с Hugging Face выключена.

Если указать адрес не на `127.0.0.1`/`localhost`, окно расширения запросит у браузера отдельное разрешение на этот адрес, и текст будет уходить на ту машину. Это ваш выбор; по умолчанию такого доступа нет.

## Что хранится и сколько

| Где | Что | Срок |
|---|---|---|
| `chrome.storage.local` | настройки | пока не удалите расширение |
| IndexedDB `mitlesen-cache`, `translations` | русские переводы; ключ — хеш немецкого текста и контекста | 180 дней с последнего чтения, не больше 30 000 записей |
| IndexedDB, `analyses` | грамматический разбор предложений (в нём есть сами немецкие слова) | 30 дней, не больше 1 500 записей |

Кнопка «Очистить кэш» в окне расширения удаляет оба хранилища. Удаление расширения удаляет всё.

Журналов запросов нет ни в расширении, ни в локальном сервисе: в `mitlesen_service.py` `log_message` выключен намеренно, чтобы текст субтитров не попадал в файлы.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `storage` | настройки |
| `offscreen` | документ, в котором работает модель перевода |
| `scripting` | подключить content-скрипт к сайту, который вы включили кнопкой «Включить на этом сайте» |
| `activeTab` | узнать домен текущей вкладки для этой кнопки |
| `declarativeNetRequestWithHostAccess` | снять заголовок `Origin` с запросов расширения к Ollama на `127.0.0.1` (иначе Ollama отвечает 403) |
| хосты `youtube.com`, `youtube-nocookie.com` | работать на YouTube без лишних вопросов |
| хосты `127.0.0.1`, `localhost` | обращаться к локальному сервису и Ollama |
| необязательный доступ ко всем сайтам | запрашивается только когда вы включаете расширение для сайта или для всех сайтов |

## Защита локальных сервисов

Любая открытая страница может попытаться отправить запрос на `127.0.0.1`. Поэтому:

- Сервис Mitlesen слушает только `127.0.0.1`. Он отклоняет запросы с заголовком `Host`, отличным от `127.0.0.1`/`localhost`/`::1` (защита от DNS rebinding), и запросы с `Origin` обычной веб-страницы. Пропускаются только запросы без `Origin` и запросы от `chrome-extension://` / `moz-extension://`. Флаг `--allow-origin chrome-extension://<id>` сужает это до одного расширения.
- Правило для Ollama снимает `Origin` только у запросов, которые инициировало само расширение (`initiatorDomains: [id расширения]`), и только к адресу Ollama на `127.0.0.1`/`localhost`. Запросы страниц к Ollama правило не трогает, и Ollama продолжает их отклонять.
- Фон расширения принимает сообщения только от своих content-скриптов и своих страниц. Сообщения проверяются по типам, адреса субтитров разбираются как URL, текст в оверлей вставляется через `textContent`, не через HTML.
