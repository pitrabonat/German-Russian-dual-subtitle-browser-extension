## Дальше, по порядку пользы

1. **Проверить на живом YouTube и Netflix руками** в обычной Opera и Opera GX: ручные и автоматические субтитры, переход между видео и сериями, реклама, фильм без немецких субтитров. Автоматическая проверка невозможна: YouTube отдаёт автоматизированному браузеру пустые субтитры, на Netflix нужен аккаунт. ~1,5 часа.
2. **Живые плееры других сайтов**: Prime Video, Disney+, Max, ARD/ZDF-Mediathek, Vimeo. Селекторы прописаны по их разметке, но вживую не проверены. Mediathek важна: там много немецкого с субтитрами.
3. **Быстрее первая загрузка модели.** 24–27 с с HDD — главное неудобство при первом запуске. Варианты: замерить на SSD; поискать базовую OPUS-MT de→ru (размер base, ≈75 млн параметров) как быструю модель на время загрузки большой; проверить WebGPU.
4. **Автосубтитры YouTube без пунктуации.** Склейка по точкам на них не срабатывает. Нужна склейка по паузам и по длине (например, до 1,2 с паузы и не больше 2 строк) и сравнение chrF на автосубтитрах — для этого нужен отдельный тестовый набор с ними.
5. **Память модели в браузере (≈1,2 ГБ).** Закрывать offscreen-документ после N минут без видео (`dispose()` уже есть, нужен таймер) и загружать снова по требованию.
6. **Грамматика:** лицо и число при «ihr» (h24) и падеж после «ein» у среднего рода по роли в предложении (h38). Сначала новые случаи в dev-наборе, потом правило; новый held-out набор, раз старый уже частично использован.
7. **Словарь:** русский перевод есть у 72 % из 1 000 частых слов. Варианты: открытый немецко-русский словарь с лицензией, совместимой с CC BY-SA (кандидатов ещё не проверял), или машинный перевод английских значений с пометкой `mt` (поле уже есть в формате статьи, такие значения карточка помечает как неточные).
8. **Тесты в Chrome и Edge** в CI (GitHub Actions на Windows): юнит-тесты и e2e в Chrome без модели, с моделью — по ручному запуску (модель не лежит в репозитории).
9. **Публикация.** Лёгкая сборка без модели для каталога дополнений Opera с загрузкой модели при первом запуске из GitHub Releases (с проверкой SHA-256), полная — в Releases.
10. **Firefox.** Там нет offscreen API, модель придётся запускать из фоновой страницы. Отдельная задача.

## Не планируется

- Обход DRM. Видеопоток расширение не трогает; субтитры читаются только из текста, который получает или рисует плеер.
- Распознавание субтитров с картинки (OCR).
- Облачные API перевода: противоречит модели приватности (см. PRIVACY.md).
