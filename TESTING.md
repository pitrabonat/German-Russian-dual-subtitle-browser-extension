# Тестирование

Все цифры ниже получены на одной машине: ноутбук Intel Core i5-9300H (4 ядра / 8 потоков), 16 ГБ ОЗУ, NVIDIA GeForce GTX 1650 Max-Q 4 ГБ, Windows 11, Node.js 24.21, Opera GX 139.0.6053.63. Проект и модель лежат на внешнем USB-диске (HDD), это заметно на времени загрузки модели.

## Как запустить

```powershell
npm run typecheck                 # tsc --noEmit
npm test                          # юнит-тесты (Vitest), ~10 с
npm run test:e2e                  # браузерные сценарии, ~4–5 мин; нужен собранный dist
node tests/e2e/run.mjs --only "youtube"        # отдельные сценарии по подстроке имени
node tests/e2e/run.mjs --browser chrome        # другой браузер
node tests/e2e/perf.mjs                        # память и CPU модели
node tests/e2e/youtube.mjs                     # проверка на живом YouTube
npm run eval:grammar              # грамматика, dev-набор
node tests/eval/grammar-eval.mjs --set heldout --fail
node tests/eval/grammar-eval.mjs --parser http://127.0.0.1:8765   # с разбором spaCy из сервиса
npm run eval:translation          # таблица chrF по сохранённым прогонам
```

Результаты пишутся в `tests/results/`: `e2e-opera-gx.json`, `perf-opera-gx-*.json`, `grammar/*.json`, `translation/*.json`, скриншоты в `screenshots/`.

## Живой YouTube

`node tests/e2e/youtube.mjs` открывает поиск YouTube, первое видео с немецкими субтитрами и проверяет строки. Последний прогон (`tests/results/youtube-opera-gx.json`): дорожка найдена, но плеер получил от `/api/timedtext` пустой ответ, поэтому строк нет. Так YouTube отвечает браузеру с `navigator.webdriver = true`. Расширение в этом случае показывает причину (проверено сценарием «пустой ответ субтитров объяснён»). Ручная проверка в обычном окне Opera для этой версии не делалась.

## Грамматика

Два набора в `tests/data`:

- `grammar-cases.json`, 132 случая: на них отлаживались правила. Категории: род существительных (12), падежи (32), спряжение (12), Partizip II (8), Präteritum (4), вспомогательный глагол (4), отделяемые приставки (30), возвратные глаголы (5), неоднозначные слова (12), склонение прилагательных (8), степени сравнения (5).
- `grammar-heldout.json`, 44 случая, написанные после правил. На них правила не подгонялись, с одной оговоркой (ниже).

Каждый случай — предложение, слово и ожидаемые значения (лемма, род, падеж, лицо, время, приставка…). Оценка считает отдельно ошибки, выданные за достоверные (`wrongAndCertain`), и ошибки с пометкой неуверенности: первые хуже.

| Набор | Движок | Случаи | Проверки | Ошибки «уверенно» | Медиана |
|---|---|---|---|---|---|
| dev | словарь + правила | 132/132 | 316/316 | 0 | 5 мс |
| dev (130 случаев, до добавления двух) | + разбор spaCy | 130/130 | 312/312 | 0 | 8,4 мс |
| held-out | словарь + правила | 42/44 (95,5 %) | 93/96 | 0 | 14 мс |

Оставшиеся ошибки held-out: «Ihr kommt immer zu spät» (лицо 2/3, число не определены, помечено как неточное) и «Sie kauft ein rotes Kleid» (Nominativ вместо Akkusativ, помечено как вероятное).

Оговорка: до последнего исправления held-out давал 41/44 и одну ошибку «уверенно»: в «Sie nimmt an dem Kurs teil» глагол определялся как *nehmen*. Причина была общей (приставка `teil` читалась как форма глагола *teilen*, и правило её пропускало), исправление тоже общее, и проверено новыми случаями в dev-наборе (`sep29`, `sep30`). Тем не менее этот случай held-out больше нельзя считать нетронутым.

## Перевод

`tests/data/translation-set.json`: 159 предложений с эталонным русским переводом, 11 категорий: бытовые (20), разговорные (15), идиомы (15), отделяемые приставки (20), длинные (10), фрагменты одного предложения (16 строк в 8 группах), неоднозначные (12), отрицание (12), модальные глаголы (12), времена (15), местоимения (12). Эталоны написаны вручную для этого проекта, по одному на предложение.

Метрика chrF2 (символьные n-граммы 1–6, β = 2, как `chrF` в sacreBLEU), по корпусу. При одном эталоне chrF занижает верные, но свободные переводы; сравнивать стоит провайдеров между собой, а не с абсолютной шкалой. Для фрагментов дополнительно считается chrF целого предложения в трёх режимах: строки по отдельности, склеенные, с принудительным префиксом.

Таблица и выводы — в [MODEL_COMPARISON.md](MODEL_COMPARISON.md).
